# Field Intake + Board Reconciliation — v0.1

## Objective

Allow technicians in the field to send ordinary evidence while ORBI TE Studio converts it into structured project facts without hiding uncertainty.

## Pipeline

```
field evidence
  -> intake normalization
  -> confidence/status tagging
  -> board device observations
  -> project reconciliation
  -> missing/conflict findings
  -> professional review queue
```

## Status vocabulary

- **observed**: visible directly in evidence.
- **reported**: supplied by a person but not independently verified.
- **calculated**: generated by deterministic engineering logic.
- **verified**: checked against an accepted verification process.
- **pending**: required data not yet available.
- **conflict**: two sources disagree.

## Reconciliation behavior

The engine compares:
- main protection;
- differential;
- branch circuit numbering;
- nominal currents;
- breaking capacity when available.

It never rewrites the project to make evidence "fit". A mismatch becomes a finding.
