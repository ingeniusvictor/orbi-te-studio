# TE1 Package README v0.1

Every generated ORBI TE Studio ZIP now includes `LEEME_ORBI_TE1.txt` at the
package root.

The README records:
- project identity;
- destination and available location;
- package generation timestamp;
- ORBI professional review status;
- reviewer name and approval timestamp when present;
- explanation of each package folder;
- SHA-256 verification instructions;
- explicit legal/operational limitations.

The README does not claim SEC approval. It states that ORBI approval is an
internal preparation/review state and that formal SEC presentation remains under
the responsibility of the authorized professional.

Because the README is created before the package index, its exact bytes are also
included in the package SHA-256 inventory.
