Purpose: realistic remote-field-input test.

Evidence currently available:
- frontal panel photograph.

Observed:
- main automatic breaker C25, 6 kA;
- differential 25 A, 30 mA;
- C1 Alumbrado: C10, 6 kA;
- C2 Enchufes comunes: C16, 6 kA;
- C3 Enchufes cocina-logia: C16, 6 kA;
- reserve modules present.

Unknown and therefore intentionally NOT inferred:
- number of lighting/outlet points;
- installed/demanded power;
- conductor sections and material;
- installation method;
- voltage drop;
- exact property address/georeference;
- measured earthing values;
- insulation/continuity/RCD test results.

This case is specifically used to prove that ORBI TE Studio distinguishes observed facts from data that still requires field verification.
